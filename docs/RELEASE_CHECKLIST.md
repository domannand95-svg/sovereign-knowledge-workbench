# Release checklist

- [ ] All Workbench tests pass on Windows and Linux.
- [ ] Base44 tests, typecheck, production build and contract comparison pass.
- [ ] Dependency audit and CodeQL pass.
- [ ] Only synthetic fixtures were used.
- [ ] Contract version and governance extensions are unchanged or reviewed.
- [ ] Source mutation, browser receipt and non-loopback tests remain green.
- [ ] Launcher scripts parse and lifecycle guidance is current.
- [ ] SBOM is generated and retained with the release evidence.
- [ ] Release archive SHA-256 checksums are generated and verified.
- [ ] A human reviewer approves after the final push.
- [ ] Tag/release signing identity is verified before publication.
- [ ] Draft PRs remain unmerged until every required check and review completes.
